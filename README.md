# 📝 Generating Poetic Texts with Recurrent Neural Networks

An AI-powered text generation project that uses **Recurrent Neural Networks (RNNs)** and **Long Short-Term Memory (LSTM)** networks to generate creative and meaningful poetry. The model is trained on a collection of poems to learn linguistic patterns, rhythm, and writing style, enabling it to produce original poetic verses from a user-provided seed text.

---

## 📌 Overview

Poetry generation is a fascinating application of **Natural Language Processing (NLP)** and **Deep Learning**. This project demonstrates how sequence models can learn the structure and style of poetry by predicting the next word or character in a sequence.

After training, the model can generate unique poems that resemble the writing style of the training dataset while maintaining grammatical coherence and poetic flow.

## 🧠 Model Architecture

The project uses a **Recurrent Neural Network (RNN)** with **LSTM layers** for sequence prediction.

**Architecture:**

- Embedding Layer
- LSTM Layer(s)
- Dropout Layer
- Dense Output Layer
- Softmax Activation

Loss Function:

- Categorical Crossentropy

Optimizer:

- Adam

---

## 📊 Workflow

1. Load poetry dataset.
2. Clean and preprocess text.
3. Tokenize words/characters.
4. Generate training sequences.
5. Build the RNN/LSTM model.
6. Train the model.
7. Save trained weights.
8. Generate new poems from a seed prompt.
